## [1.0.0] - 2024-01-XX

### Added
- Grid-based window management system
- Keyboard shortcuts for window movement and resizing
- Mouse-based window snapping functionality
- Multi-monitor support with independent grid settings
- Visual grid preview with customizable colors
- Status bar menu for quick access to settings
- Accessibility permissions handling
- Launch at login functionality
- Settings persistence with UserDefaults

### Features
- **Window Movement**: Move windows within screen using keyboard shortcuts
- **Window Resizing**: Resize windows when they reach screen edges
- **Cross-Screen Movement**: Move windows between multiple displays
- **Mouse Snapping**: Drag windows to screen edges for instant snapping
- **Grid Customization**: Set up 1x1 to 6x6 grid layouts per screen
- **Visual Feedback**: Customizable accent colors for grid preview
- **Keyboard Shortcuts**: Fully customizable global hotkeys

### Technical
- Accessibility framework integration for window manipulation
- SwiftUI for modern user interface
- Combine for reactive data binding
- KeyboardShortcuts for global hotkey management
- LaunchAtLogin for automatic startup
